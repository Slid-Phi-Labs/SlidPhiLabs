## 1. What the best closed-loop discovery labs actually do

The reference implementation is **Robin** (FutureHouse), a multi-agent system published in *Nature* in 2026 that integrates literature-based hypothesis generation with autonomous analysis of laboratory data in one continuous workflow. The loop is: disease of interest in → literature agents propose mechanisms and an in-vitro assay → candidates ranked → humans run the assay → raw data back to the analysis agent → insights feed the next round of candidates. The cycle continues until a human has a satisfactory drug candidate.

- **Specialised roles, not one general agent.** Robin uses Crow and Falcon (literature search agents built on PaperQA2, concise vs. deep) and Finch (a data-analysis agent that writes and executes code in Jupyter notebooks for RNA-seq and flow cytometry). "Robin utilizes specialized language agents for literature search (Crow and Falcon) and data analysis (Finch) to enable semi-autonomous scientific discovery." — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **Hypothesis → test → verdict, iterated.** Robin identified 10 causal disease mechanisms for dry age-related macular degeneration (dAMD), ranked in-vitro models with an LLM-judged tournament, proposed 30 drug candidates, had the top 5 tested in a retinal pigment epithelium (RPE) phagocytosis assay, then used the results to propose follow-up RNA-seq and a second candidate round. Round two identified ripasudil (a glaucoma drug approved in Japan), which increased RPE phagocytosis 1.89-fold vs. DMSO control, confirmed in primary human RPE cells from a donor over 60. — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **The loop is lab-in-the-loop, not lab-free.** Humans executed the experimental protocol and uploaded raw data (.FCS files, gene counts); Robin never ran the wet lab itself. "The key intellectual steps of the scientific method were thus automated while coordinating with scientists throughout the experimental loop." — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **Consensus over single runs for analysis.** Finch's stochasticity means identical prompts and data give varying results, so Robin launched eight independent Finch analysis trajectories per dataset and ran a meta-analysis to a consensus conclusion. Finch scored 86% on RNA-seq and 100% on flow cytometry against expert-generated rubrics (n = 3 runs each). — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **The sibling system, Co-Scientist (Google DeepMind),** is also a multi-agent generate/debate/evolve system validated in biomedicine — drug candidates and combination therapies for acute myeloid leukemia shown beneficial in cell-line experiments, plus new drug targets for liver fibrosis — with the same caveat: rigorous preclinical and clinical assessment is still required. — [TechXplore, 2026-05-20](https://techxplore.com/news/2026-05-ai-scientific-discoveries.html)
- **Generalist agents follow the same shape.** Biomni (Stanford, published in *Science* July 2026) builds a "Biomni-E1" environment from 2,500 recent papers across 25 biomedical subfields — 150 specialised tools, 105 software packages, 59 databases — with an agent architecture built on intelligent resource selection (retrieve only the relevant tools), a code-as-action interface, and adaptive planning. On a 443-question benchmark it averaged 57% accuracy vs. 30% for general LLMs and 25% for specialised drug-R&D agents, and matched or exceeded senior postdocs/professors on single-cell annotation, rare-disease diagnosis and GWAS causal-gene detection, at several to tens of times the speed. It also generated executable liquid-handling code (PyLabRobot, Hamilton STAR) for cell-viability assays — dry-lab to wet-lab execution in one chain. — [VCBeat, 2026](https://www.vcbeathealth.com/article/59686)
- **Cost and time are measured, not asserted.** A full Robin run (45 Crow + 30 Falcon calls) cost US$10.76 on average; the workflow cut estimated cognitive labour from 359–424 human hours to under 2 hours, synthesising 551 references in ~30 minutes vs. ~294 hours manually. — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **The stack framing.** An "AI scientist" system is usefully defined as covering problem framing → hypothesis generation → experiment design → execution (in silico and/or physical lab) → analysis/interpretation → documentation → iteration, in four layers: reasoning/agent, tool, execution, evaluation/oversight (automated reviewers, safety filters, provenance, reproducibility, benchmark measurement). — [AI Blueprint, Substack, 2026](https://aiblueprint.substack.com/p/ai-scientist-systems-for-automated)

## 2. How multi-agent research handoffs stay honest

- **The plan is a file, not prose in a supervisor's head.** Repuragent v2 stores and updates the plan as `plan.md` in the conversation's output folder, "so progress cannot drift from what actually happened, a task can be resumed, and a follow-up can read the work log. This enforces deterministic plan monitoring." The supervisor writes a written brief per step, delegates, checks what comes back, and updates `plan.md`. — [Repuragent, pharmbio GitHub](https://github.com/pharmbio/repuragent)
- **Context isolation between roles.** In Repuragent, "the supervisor holds the whole conversation, and each specialist receives a written brief from it. When a sub-agent finishes its job, it returns only its final message to the supervisor's context." — [Repuragent, pharmbio GitHub](https://github.com/pharmbio/repuragent)
- **Need-only context is a scored contract, not a vibe.** PerspectiveGap (110 scenarios, 27 commercial models) tests whether an orchestrator writes role-specific prompts that give each sub-agent exactly the fragments it needs — no more, no less. Average combined pass rate was only 14.9% (GPT-5.5 led at 62.0%); average leakage rate was 246.5% (a per-scenario leak-event count). The recurring failures: leaking distractors, exposing out-of-role information, dropping shared context, confusing artifact ownership, placing instructions where the sub-agent cannot see them. — [PerspectiveGap, arXiv:2606.08878](https://arxiv.org/html/2606.08878v1)
- **Supervisor pattern, verified merge.** The supervisor pattern — lead agent writes a brief per worker, workers run in parallel with their own context, lead verifies and merges before anything reaches a system of record — is the pattern to learn first. Two pre-split tests: can the lead write a brief a worker can act on without the lead's conversation, and can the lead verify the worker's output without redoing the work? If either fails, stay with one agent. — [QueryNow, 2026](https://www.querynow.com/ai-agents/orchestration/multi-agent-patterns)
- **Living spec as the handoff artifact.** A durable, machine-readable "living specification" persists externally and survives complete context replacement; a Verifier agent at handoff points checks results against the spec rather than only the local diff. Anthropic's guidance identifies a progress file plus git history as the handoff mechanism that lets agents resume with a fresh context window. — [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)
- **Voting must be anonymous and blind to tallies.** In multi-turn multi-agent orchestration (4 LLMs on GPQA-Diamond, IFEval, MuSR), orchestration matched or beat the strongest single model (avg. 81.2% vs. best single 80.5%), but revealing authorship raised self-voting (GPT-5: 81.0% → 88.4%) and consensus ties (14.1% → 23.2%), and showing live vote tallies raised first-voted selection from 54.1% to 67.8% — herding. In 64% of orchestration errors, at least one agent had produced the correct answer; the consensus still converged on a wrong majority. Design consequence: judge/rank votes anonymously, hide running tallies, and never let a majority vote override a falsifier. — [Tian et al., UPenn, 2026](https://sharathg.cis.upenn.edu/assets/pdf/76_hrfUAAAAJ_86PQX7AUzd4C.pdf)
- **The report agent is tied to the evidence the run produced.** Repuragent's Report agent "summarizes the full run into the final answer, tied to the evidence the run produced" — not a free-form summary. — [Repuragent, pharmbio GitHub](https://github.com/pharmbio/repuragent)
- **Checkpoints and resume-from-failure.** Errors compound — a worker that misreads the brief at step two poisons every step after. Anthropic's fix: checkpoints with resume-from-failure and releases that leave in-flight agents alone. — [QueryNow, 2026](https://www.querynow.com/ai-agents/orchestration/multi-agent-patterns)

## 3. Evidence-grading practice for drug repurposing claims

- **A computational hit is a hypothesis, not a finding.** The credible sequence is fixed: (1) computational prioritisation narrows thousands of pairs to a shortlist; (2) in-vitro or phenotypic assays test top candidates in relevant cell models; (3) retrospective EHR/claims analysis checks whether patients already taking the drug show altered outcomes; (4) prospective clinical trials generate the efficacy data regulators require. "Skipping any one of those steps, particularly the retrospective real-world check, is a common reason computational candidates fail to replicate when tested prospectively." — [Drug Discovery News, 2026](https://www.drugdiscoverynews.com/ai-powered-drug-repurposing-finding-new-uses-for-existing-molecules-17375)
- **The gold-standard exemplar is baricitinib.** An AI-enhanced knowledge graph plus expert-guided queries flagged the rheumatoid-arthritis drug for COVID-19 on a dual antiviral/anti-inflammatory mechanism; the ACTT-2 randomised phase-3 trial then showed improved time to recovery (EUA Nov 2020), CoV-BARRIER showed a mortality reduction, and full FDA approval followed in 2022. "A computational hypothesis generated the signal, but randomized clinical trials, not the algorithm, established clinical efficacy in stages." — [Drug Discovery News, 2026](https://www.drugdiscoverynews.com/ai-powered-drug-repurposing-finding-new-uses-for-existing-molecules-17375)
- **Three-phase staged integration is the field's proposed framework.** Phase 1: high-throughput screening with network/data-driven (incl. LLM) methods as the hypothesis engine. Phase 2: mechanistic validation with structure-based docking + molecular dynamics, omics signature-reversal or causal inference, adverse-event corroboration. Phase 3: clinical translation and safety verification, with outcomes feeding back into Phase 1 models to close the loop. "The translational value of any computational repurposing framework is determined not by its in silico ranking performance alone but by whether its predictions can be confirmed in prospective clinical settings." — [MDPI Biomolecules review, 2026](https://www.mdpi.com/2218-273X/16/6/830)
- **LLM predictions currently have the shortest validation chain.** Most LLM-based repurposing studies rely on 5-fold cross-validation or repeated runs on benchmark datasets; validation "depends almost entirely on manual expert review and hallucination checks, constituting the shortest validation chain among all paradigms," and "bona fide clinical validation… remains exceedingly rare across all categories." Metrics are incommensurable across paradigms (binding energy vs. AUROC/AUPR vs. validity/novelty) and "do not translate directly into clinical utility." — [MDPI Biomolecules review, 2026](https://www.mdpi.com/2218-273X/16/6/830)
- **Triangulate three independent evidence channels, then merge with explicit weights.** DrugAgent runs three specialist agents in parallel — an ML agent (DeepPurpose DTI models on BindingDB), a knowledge-graph agent (DGIdb, DrugBank, CTD, STITCH; score decays with shortest-path hops), and a literature search agent — and a Coordinator merges them as S_merged = α·S_AI + β·S_KG + γ·S_Search, reporting individual scores alongside the merged one so the user sees how each channel contributed. Ablation: removing the AI agent was the most damaging (MSE 1.836 → 52.349, R² 0.431 → −15.228); removing the KG agent also hurt substantially. The authors are explicit that the search agent's keyword scoring of Google snippets "serves as a preliminary screening tool rather than a comprehensive literature review system" — it does not read full papers. — [DrugAgent, arXiv:2408.13378](https://arxiv.org/html/2408.13378v3)
- **Grade evidence by source tier, and keep the tiers visible.** The MDPI review's taxonomy: mechanism-driven methods (structure, omics, fuzzy logic, adverse-event) give deep mechanistic insight and are required for rigorous validation and explanation; network methods enable systematic large-scale prioritisation; LLM/text-mining methods are semantic front ends for extraction and hypothesis generation. A claim's grade should name which tier supports it — a literature-only signal is not a mechanism-validated signal. — [MDPI Biomolecules review, 2026](https://www.mdpi.com/2218-273X/16/6/830)
- **Regulatory strategy belongs in the earliest triage.** The FDA 505(b)(2) pathway lets a sponsor reference existing safety data while generating new efficacy evidence; the FDA's CURE ID program collects clinician-reported real-world repurposing experiences. A molecule with an expired patent but a strong mechanistic rationale may still need orphan-drug incentives or public-private funding to reach a filing. — [Drug Discovery News, 2026](https://www.drugdiscoverynews.com/ai-powered-drug-repurposing-finding-new-uses-for-existing-molecules-17375)
- **Negative data is the hard problem.** Confirmed drug–target interaction pairs are scarce relative to the space of possible pairs, and "selecting true negative training data is genuinely difficult because a lack of reported activity does not confirm a lack of biological effect, which skews model confidence and complicates benchmarking." — [Drug Discovery News, 2026](https://www.drugdiscoverynews.com/ai-powered-drug-repurposing-finding-new-uses-for-existing-molecules-17375)

## 4. Benchmark / stop-rule design

- **Component benchmarks do not predict collaborative success.** A review of 14 benchmarks (BLUE, BLURB, BioASQ, LAB-Bench, BioPlanner, CRISPR-GPT, BioDiscoveryAgent, etc.) finds they assess isolated capabilities — literature understanding, hypothesis generation, experimental planning — but never integration, memory, or adaptability across the research lifecycle. "A high-scoring system on isolated tasks can exhibit catastrophic failures in real scenarios by forgetting constraints, resisting feedback, or mismanaging session continuity." The four gaps: no integrated proposal evaluation, no validated lab-tool-use framework, no wet-lab reproducibility framework (RENOIR/CORE-Bench cover ML output, not AI-designed experimental replication), and no closed-loop iteration (systems do not learn from experimental outcomes). Reported warning signs: 90%+ hallucination rates for scientific citations with traditional LLMs (ScholarQABench), poor protocol error detection (BioLP-bench). — [Evaluating AI Co-Pilots in Biomedical Research, arXiv:2512.04854 (EmergentMind summary)](https://emergentmind.com/papers/2512.04854)
- **Evaluate the process, not just the outcome.** BiomniBench is "the first process-level benchmark for LLM agents on real-world biomedical research": 100 data-analysis tasks curated from *Nature*, *Cell*, *Science* papers, run across four agent harnesses and frontier + open-weight models. Finding: "agents reliably ground claims in real sources yet consistently fall short on method selection, biological interpretation, and scientific reasoning," and the harness shifts scores by more than the gap between successive model generations. — *Note: the bioRxiv full text was unreadable (HTTP 429); this item rests on the Tavily snippet and is recorded here as UNVERIFIED — do not cite it as a finding until the full text is read.* (See read log.)
- **Score against a withheld reference with weighted rubrics.** ResearchClawBench builds each of 40 tasks around a published paper, withholds the target, and scores the system's report and artifacts against expert-written weighted criteria (RADS — Reference-Anchored Discovery Score, 100 points; 50 = target-paper-level evidence). Best autonomous agent (Claude Code) averaged 21.5; best model 20.7 — far below the re-discovery mark. Error analysis over 280 runs: failures concentrate on experiment-design mismatch, evidence mismatch, and missing scientific core. The benchmark tests "whether the agent preserves the protocol and evidence needed to support the scientific claim," not whether it can produce a fluent report. — [ResearchClawBench, alphaXiv](https://www.alphaxiv.org/abs/2606.07591)
- **Use pass^k (consistency), not single-run pass rate.** "Pass^k testing — evaluating whether an agent succeeds across multiple independent attempts — is a more reliable predictor of real-world stability than single-run success." The CLEAR framework (Cost, Latency, Efficacy, Assurance, Reliability) showed 0.83 correlation with production success vs. 0.41 for accuracy-only evals, and documented task costs from $0.10 to $5.00 among configurations with similar accuracy. "Map each metric to an explicit release threshold before you run the first eval." — [Splunk, 2026](https://www.splunk.com/en_us/blog/learn/multi-agent-benchmarks.html)
- **Ablate to prove the architecture earns its keep.** Robin's ablation: replacing Crow/Falcon with plain o4-mini calls "led to a dramatic increase in hallucinated references"; o4-mini hallucinated 44.5% ± 6.37% of references in assay proposals vs. 0% for Crow. The LLM judge (Claude Sonnet 3.7, pairwise tournament + Bradley–Terry–Luce) matched experts' top-10 at 7.25/10 on average (vs. ~3.5 expected by chance) and was more self-consistent than human experts (88% vs. 61% agreement on repeated identical comparisons). A general-purpose agent (OpenAI Deep Research) given the same prompt produced 0 hits in the assay and never suggested ROCK inhibition. — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **Stop rules the field uses implicitly.** Robin's loop stops when "a human has a satisfactory drug candidate" — a human verdict, not a model threshold. ResearchClawBench's 50-point mark is a re-discovery threshold: below it, the system has not reproduced reference-level evidence. Repuragent's plan "can wait at its approval gate indefinitely" — the run pauses for a human rather than proceeding on stale authority. — [Nature, 2026](https://www.nature.com/articles/s41586-026-10652-y); [ResearchClawBench, alphaXiv](https://www.alphaxiv.org/abs/2606.07591); [Repuragent, GitHub](https://github.com/pharmbio/repuragent)
- **Measure cost alongside accuracy.** Multi-agent systems use ~15× the tokens of a chat interaction (single agents ~4×); token usage alone explained 80% of performance variance on BrowseComp. Anthropic's research system beat a single agent by 90.2% on its internal evaluation — at that 15× token price. Any stop rule that ignores cost will approve configurations that are accurate and unaffordable. — [QueryNow, 2026](https://www.querynow.com/ai-agents/orchestration/multi-agent-patterns); [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)

## 5. What NOT to do (known failure modes)

- **Do not let a single agent's error become the next agent's fact.** "Minor errors from upstream agents (incorrect parameters or hallucinated values) are consumed as valid inputs by downstream agents without detection. The deviation amplifies at each level along the collaboration chain." Recovery: schema validation gates between agents; file-based communication contracts. — [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)
- **Do not trust a fluent report.** ResearchClawBench's premise: "A fluent report, a working script, or an appealing demo does not, by itself, show that a system used the right experiment or recovered the evidence behind a finding." Best agents score ~21/100 against reference-level evidence. — [ResearchClawBench, alphaXiv](https://www.alphaxiv.org/abs/2606.07591)
- **Do not flatten every role into the same prompt.** PerspectiveGap's core finding is that orchestrators leak out-of-role information and drop required fragments (average pass rate 14.9%). The MAST study catalogued 14 failure modes in three groups — system design/specification, inter-agent misalignment, task verification — and coordination failures are 36.94% of all failures across AutoGen, CrewAI and LangGraph (1,600+ annotated traces). — [PerspectiveGap, arXiv:2606.08878](https://arxiv.org/html/2606.08878v1); [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)
- **Do not let the verifier agree with the generator.** Verifiers show agreement bias, "tending to agree with prior outputs rather than independently evaluating them," and agents write code that passes tests while silently breaking a contract defined elsewhere. Recovery: independent dual-agent verification (reviewer ≠ tester) plus a deterministic enforcement layer / boolean exit gate that blocks premature exit. — [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)
- **Do not run unbounded loops.** Feedback loops (A triggers B triggers A) and single-agent tool-call spins are documented failure modes. Recovery: intra-task iteration caps plus inter-phase boolean exit gates — a cycle cannot declare completion unless explicit success criteria are written to a shared state file. — [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)
- **Do not parallelise coupled work.** "Subagents which cannot see each other's traces make conflicting decisions"; a single-threaded agent with context compression wins on coupled tasks. Multi-agent pays off on broad, parallel, high-value-per-task work; on coupled tasks it loses. "Measure on your own evaluation set before deciding." — [QueryNow, 2026](https://www.querynow.com/ai-agents/orchestration/multi-agent-patterns)
- **Do not let context drift.** Agents lose the codebase/experiment state as context fills (factual drift) or drift from the original specification over long sessions (alignment drift). Recovery: a Verifier at handoff points using the persistent living spec as the correctness standard. — [Augment Code, 2026](https://www.augmentcode.com/guides/multi-agent-orchestration-architecture-guide)
- **Do not give workers the supervisor's rights.** "A worker that inherits the supervisor's rights is an over-permissioned agent with its own prompt-injection surface. Give each worker an identity with narrower rights, log its tool calls under that identity." — [QueryNow, 2026](https://www.querynow.com/ai-agents/orchestration/multi-agent-patterns)
- **Do not ship on component scores.** A system can score 90%+ on isolated benchmarks and still fail in real workflows by forgetting constraints or resisting feedback; wet-lab reproducibility of AI-designed experiments is unmeasured by current frameworks, "leading to potential large-scale error propagation." — [Evaluating AI Co-Pilots, arXiv:2512.04854](https://emergentmind.com/papers/2512.04854)
- **Do not present LLM output as evidence to regulators.** "The FDA and EMA currently lack established frameworks for validating AI-generated therapeutic hypotheses; unverified LLM outputs cannot be accepted as evidence in regulatory submissions." — [MDPI Biomolecules review, 2026](https://www.mdpi.com/2218-273X/16/6/830)
- **Do not skip the safety gates.** Robin's guardrails: prioritise candidates with established safety profiles; search for known toxicities/off-target interactions; treat all outputs as therapeutic hypotheses requiring standard pre-clinical validation; run all queries through an LLM classifier checking unsafe topics; use safety-aligned off-the-shelf models. — [Nature, Ghareeb et al. 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **Do not build on one vendor's model.** The leading model changes every few months; a platform built on one provider inherits that provider's pricing and roadmap. Route each task to the best model for it; keep the architecture model-agnostic (Robin's authors note this explicitly). — [BenchSci, 2026](https://www.benchsci.com/news/best-ai-platforms-for-drug-discovery); [Nature, 2026](https://www.nature.com/articles/s41586-026-10652-y)
- **Do not start with autonomy; start with the bottleneck.** Bio-IT World workshop guidance (via Tavily snippet — NOT verified in full text, see read log): organisations should ask where their workflow bottlenecks are, not "can we build autonomous AI scientists?"; autonomy needs data pipelines, validation layers, memory, observability, tool interoperability, governance, human oversight and trust — without those foundations you get demos that do not survive. *Snippet-only — excluded from findings above; recorded here only as an unverified lead.*

## 6. Design implications carried into the builder brief

See `~/workspace/biolab/research/best-methods-brief.md` for the 8 design decisions this research implies. In one line: the biolab is a **lab-in-the-loop, supervisor-pattern system with a file-based living plan, need-only briefs, consensus analysis, explicit evidence tiers, weighted multi-channel scoring, process-level benchmarks with pass^k and cost, boolean exit gates, and a human verdict as the only stop rule** — because that is what the published systems that actually produced a validated result do, and the failure modes above are what happens when any piece is skipped.
