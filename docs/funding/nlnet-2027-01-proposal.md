## Working title

Exact residual selection for structured records

## What

A small free-software tool that packs structured records (tables, logs,
timestamps, small integers) and keeps a candidate only when two tests pass:
the decoded bytes match the input exactly, and the packed file is strictly
smaller than the other exact candidates. A smaller file that fails the byte
check is discarded.

The uncertain part is a reversible ternary residual step. Each residual is
written as one of three symbols, and the part that does not fit is stored as
an exact remainder, so the original integer can be rebuilt with no rounding.
Phase I of the lab's NSF plan is the experiment that says whether this step
is actually smaller than xz -9 and zstd -19 on a fixed corpus. This grant
would pay for publishing the specification and the reference implementation
under a free license, whatever the size result is.

## What is already measured

Silesia corpus, 211,938,580 bytes. An earlier packing in this line, TNSSRC,
produced 48,541,366 bytes against xz -9 at 48,795,480 bytes, and the decode
check passed on 12 of 12 files. A related method, Strand, produced 55,108,451
bytes and did not beat zstd -19 at 52,910,409 bytes. The ternary rule plus
exact selection has not been shown to win. That is the research.

## License and deliverables

All software written under the grant is released under a recognized free
license (AGPL-3.0-or-later, matching the lab's TNSSRC grant, unless NLnet
requires a different OSI license). The specification is published as open
text. The result table lists input size, each candidate size, whether decode
matched every input byte, and which candidate was kept. Candidates that fail
the byte check are not published as wins.
