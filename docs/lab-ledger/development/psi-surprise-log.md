# psi surprise log — HN harvest template

Ops template for Show HN inbound. One row per surprise. Feed tweak ids from here; do not invent psi rates.

| date | HN comment link | surprise / pain | proposed psi tweak id | status |
|------|-----------------|-----------------|-----------------------|--------|
| YYYY-MM-DD | https://news.ycombinator.com/item?id=… | one-line pain the commenter hit | tweak-NNN or blank | open / wired / wontfix |

## How to use

1. After Show HN posts, paste each useful comment as a row.
2. `surprise / pain` is the user's words, shortened — not a sales rewrite.
3. `proposed psi tweak id` stays blank until a real tweak is scoped in `~/psi`.
4. Close the row when wired, or mark `wontfix` with a one-word reason in status.
