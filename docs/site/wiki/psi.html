Boot the runtime. Keep the receipts.

psi boots a persistent working runtime. A doctor gate checks the wiring, every boot lands in the observatory log, retrieval scores past notes, and a savings meter counts avoided tokens. PSI Meter is $25 a seat a month, $250 a seat a year; PSI Embed is the unified grant.

What it is

psi is the licensed runtime tree: a boot script, a doctor gate that reports PSI-GREEN, an append-only observatory log of boots and fixes, a retrieval scorer over past notes, preflight gates, thrift rites, and a savings meter against a conservative price book. Commercial only (PSI Meter / Org / Embed) — not an AGPL offer. PERsiST is a different product face with unset rates; do not confuse the two.

How it works

  1. Take a license.
  2. Export SLIDPHILABS_ROOT to your Slid Phi Labs checkout (example on Git Bash for Windows: SLIDPHILABS_ROOT=/c/Users/ptasz/SlidPhiLabs).
  3. Run the boot.
  4. The doctor checks the wiring.
  5. Work; every fix lands in the observatory.
  6. Retrieval surfaces past answers before new spend.

Fail-closed: without SLIDPHILABS_ROOT set to a real lab checkout, the tools gate refuses and the doctor reports RED by design. That is not a broken install — export the root, then re-run. Do not invent a bypass.

What you receive

You receive the licensed runtime tree: boot, doctor, retrieval, preflight gates, thrift rites, the observatory log format, and the savings meter. Lab Pass includes a PSI Meter seat.

Price

Commercial only. PSI Meter is $25 a seat a month, $250 a seat a year, including 250,000 logged calls a month, then $2 per additional 100,000 calls, with a customer-set monthly cap and an alert at 80% of the cap. Free: 1 seat, 10,000 calls a month, 7-day retention. PSI Embed, the commercial code license, is the unified grant: $490 a year for one product, $190 for the first 10 grants, $390 each for 3 or more products. Written, human-fulfilled, one product and one year, renewal at the then-current price. There is no AGPL purchase path for new seats. The psi-month and psi-year SKUs are retired. Lab Pass ($495 a year) includes a PSI Meter seat. Teams seat a crew with psi Org. Read /pricing for the current numbers.
