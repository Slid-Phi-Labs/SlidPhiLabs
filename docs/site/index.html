CuNi

One rule, the same everywhere.

When you write a rule for an agent in one language and move it to another, it can quietly change meaning. CuNi catches that. It checks that the rule means the exact same thing in every language it runs in. If it doesn't match, CuNi refuses to ship it. If it passes, you can trust it.
