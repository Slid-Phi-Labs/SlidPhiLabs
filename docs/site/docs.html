For developers

One API: shrink a file, then restore it.

Same product the pricing page sells. Send a file, get a smaller one back, restore every byte. First 1 GB free once per address, lifetime. Then $0.25 per GB of input. Pro is $25 a month, 100 GB included, then $0.20 per GB. Zeros become 8 bytes on the free demo.

Zeros (free demo)

python3 -c "open('z.bin','wb').write(bytes(1000000))"
curl -sS -X POST https://www.slidphilabs.com/v1/compress \
  -H 'content-type: application/octet-stream' --data-binary @z.bin

A real file, then restore

curl -sS -X POST https://www.slidphilabs.com/v1/compress \
  -H 'content-type: application/octet-stream' --data-binary @file.bin > out.json
curl -sS -X POST https://www.slidphilabs.com/v1/decompress \
  -H 'content-type: application/json' --data-binary @out.json

Or one loop: POST /v1/process with the same body. Same engine: POST /v1/specialist.

Meter: first 1 GB free once per IP address (lifetime, no monthly reset), then $0.25/GB of input. Customer-set monthly spend cap (default $25), alert at 80% of cap/allowance. Pro $25/month (100 GB included, then $0.20/GB). Quote: POST /v1/ppp-quote. Prices: /pricing, source of truth pricing.json.

Warrant (pairs with Agent-Rider): POST /v1/warrant/issue with X-Agent-Rider, then POST /v1/warrant/receipt with X-Agent-Warrant. Discovery: GET /v1/warrant.

Canonical prefix is /v1/* — /api/* remains a supported alias resolving to the same handlers.
